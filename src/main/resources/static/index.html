📡 参数调试流程

  1. 输入根目录 → 点击 扫描，自动发现所有站和日期
  2. 点击 ⚙ 配对组 → 创建基站→测站的配对关系
  3. 选择配对组 → 多选日期（Ctrl+点击）→ 设置时段范围 → 加载
  4. 调整参数组合 → 点击 ▶ 评估，实时查看进度日志
  5. 查看评估结果：Fixed率对比、最佳参数的坐标偏差图
  6. 点击 📊 轨迹图 查看RTKPLOT风格的定位轨迹

📊 评估结果解读

  • Fixed率：固定解占比，越高越好（>80%为优）
  • Float率：浮动解占比，说明模糊度未固定
  • Single率：单点解占比，未使用差分
  • Ratio：模糊度检验比值，越大固定越可靠
  • 坐标偏差：N/E/U相对固定解均值的偏差范围

🗺 轨迹图说明
